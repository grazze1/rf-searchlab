# 开发指南

Python 3.12+。执行 `scripts/setup.ps1` 安装项目锁定环境，或使用 README 中的等价命令。缓存与证据写入 `.work/`。

`scripts/check.ps1` 检查格式、静态诊断、公共入口类型、pytest、整体和关键模块覆盖率。整体目标 80%，关键模块 90%；阈值失败保持非零退出。算法内部类型尚未全部达到严格静态检查，实际范围记录在验证报告中。

新增策略应通过公开状态选择 `Intent`，由应用层执行后接收 `Response`。禁止导入仿真器或评分真值。注册策略、增加合成回归和观测等价测试，再加入比较实验。

几何测试使用全点对直径、独立圆枚举、保守单元检查等独立判据。协议测试验证拒绝请求无状态变化；恢复测试模拟写入与状态提交之间的进程中断。

执行 `python scripts/build_release.py` 生成 wheel、源码分发包和可移动源码 ZIP。打包脚本只接受明确目录和文件，拒绝缓存、运行日志、本机路径及越界符号链接。发布到外部服务是单独的人工操作。

Windows CI 配置位于 `.github/workflows/ci.yml`，使用固定提交的官方 checkout/setup-python 行动、只读仓库权限和本地构建，不自动上传或发布。远程 CI 是否执行见验证报告；本地检查不能冒充远程执行结果。
