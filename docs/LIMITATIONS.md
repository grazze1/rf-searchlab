# 适用范围与限制

- 标准物理参数固定，规划与覆盖证明只适用于文档列出的范围。当前不是任意速度、频道数、方向宽度的通用仿真配置器。
- 主动测点规划使用有限候选与示向区间外包；不能证明连续空间的全局最优。
- 恢复只适用于本包内确定性环境和一致的版本/输入；新进程重新计算墙钟预算。损坏、截断或不一致日志拒绝续跑。
- Python 组件之间的真值隔离用于可信策略工程约束，不等价于恶意插件沙箱。
- 统计结果仅适用于已记录的合成样本；成功率与耗时不能外推到所有环境。
- Web 面向本地单用户。远程部署、多用户授权与真实设备控制不在当前发行范围内。
- 发布验收以 `VALIDATION.md` 的实际结果为准；依赖漏洞全扫描和外部 CI 的未执行项会单列。
