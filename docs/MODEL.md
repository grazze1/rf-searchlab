# 模型说明

## 标准仿真配置

| 参数 | 值 |
|---|---:|
| 信号源圆域半径 | 1800 m |
| 频道 | 1–20，每频道最多一源 |
| 标准场景源数 | 1–16，策略不知道实际数量 |
| 接收距离 | 每源固定在 1000–1500 m |
| 定向源可见范围 | 固定闭半平面，包含边界 |
| 返回示向误差 | 有界 ±1° |
| 近距离提示 | 可接收且距离 ≤5 m |
| 模拟服务成功距离 | ≤20 m，不受发射方向影响 |
| 移动速度 | 5 m/s |
| 测量费用 | 移动时间 +5 s，切频道再 +1 s |
| 服务费用 | 移动时间 +3 s，成功再 +2 s |

探测器初始位置为原点，初始频道为 1。探测器可移动到源域之外，序列化坐标上限为每轴 ±2,000,000 m。

默认误差是固定种子和位置的平滑空间函数；重复位置得到相同误差，重复测量不能当成独立样本平均以缩小硬误差界。返回示向量化到两位小数，量化后仍在 ±1° 内；虚拟时间逐动作累计到微秒。

## 几何与证书

定位区域由测向误差楔与保守圆域约束构成。多边形表示使用外包，不能把采样内接区域当成保证区域。直径圆覆盖与最小包围圆分别计算。

全向负观测可在满足最小接收距离条件下排除区域；混合环境中的无信号可能来自方向盲区。混合策略使用连续位置/方向的覆盖证书，证书绑定到已接受的同频道负观测。清除完成状态与停止条件依赖公开证据，事后评分用于核对矛盾。

FIM 与可见性概率只用于候选排序。测点规划对有限候选及未来示向区间计算保守上界，不提供连续全局最优证明。内置模型是合成研究模型，不作为真实硬件的安全或性能认证。
