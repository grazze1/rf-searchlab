# 使用指南

## 定位分析

在“定位分析 → 区域与覆盖”输入 `sensors_m`、`bearings_deg` 和可选的 `epsilon_deg`。坐标单位为 m，角度单位为度，东向为零、逆时针为正。测点数与示向数必须相等。输出分别给出区域状态、顶点、直径、直径圆是否覆盖以及最小包围圆；无界区域不伪造有限尺寸。

“主动测点规划”读取一个测点与示向。`fast` 使用较少候选和角度区间，`accurate` 提高离散精度。图中颜色表示保守定位半径上界，选择 `recommended` 查看推荐位置和对应接收距离保证。示例文件位于 `examples/`。

## 搜索任务

选择全向或混合信号环境、策略、场景种子、源数和分布，点击“开始离线任务”。策略不读取源数、位置、方向或接收半径。场景生成器与事后评分器可以访问这些数据。

任务运行时可在动作提交边界暂停、继续或取消。关闭进程后，支持恢复格式的新任务可通过 `resume-run` 继续；恢复先核对输入与配置哈希，再逐步重建和核对历史动作/响应。损坏、截断或不匹配的记录会被拒绝续跑，仍可查看完整有效前缀。

恢复仅适用于内置确定性仿真器。新进程重置墙钟预算；虚拟时间和已完成动作从日志保留。同一运行的进程锁阻止并发执行。

## 回放与导出

历史列表包含完成和未收尾任务。时间轴、前后单步与自动播放仅使用已记录事件，不再次执行策略。教学真值图层默认关闭，开启后会明确标记评分侧位置。导出完整事件或已有报告；尚无报告的中断任务仍可回放。

## 策略比较

`benchmark` 在执行前冻结场景种子、规格和哈希。同一场景的不同策略使用相同固定误差场。所有失败行保留；成功率与成功局条件耗时分开报告。smoke、regression、stress 的种子区间互不相交。`--limit` 可减少每类环境的场景数，报告必须保留实际样本量。
